Privacy Policy

Last updated: September 03, 2025

This Privacy Policy explains how Passport Photo App ("the Application", "we", "us", or "our") collects, uses, and protects information when you use our mobile application.

Privacy-first: Passport Photo App is designed with a privacy-first approach, and all sensitive processing is performed entirely on-device.

1. Interpretation and Definitions

Application: Passport Photo App, the iOS application provided by the Company.

Company: Passport Photo App.

Device: Any device that can access the Application, such as a smartphone or tablet.

Personal Data: Any information that relates to an identified or identifiable individual.

Usage Data: Anonymous and aggregated data collected to understand how the Application is used.

2. Face Data Processing (Important)

The Application uses on-device face detection solely to assist with photo alignment, cropping, and compliance with official passport, ID, visa, and driver's license photo requirements.

Face data is handled as follows:

  • Face data is processed entirely on the user's device.
  • Face data is NOT collected, stored, retained, logged, transmitted, or shared.
  • Face data is NOT sent to our servers or to any third party.
  • Face data exists only temporarily in memory during real-time processing and is immediately and permanently discarded once processing is completed.

Prohibited uses: Face data is never used for facial recognition, user identification, tracking, profiling, advertising, or analytics.

3. Data Retention

The Application does not retain face data for any length of time. All face-related processing occurs in real time and is deleted instantly after processing. No biometric or facial data is stored on the device or on any servers.

4. Analytics and Usage Data

The Application uses privacy-friendly analytics tools (such as Google Analytics for Firebase) to collect aggregated and anonymized usage statistics.

Examples include which screens are opened, how often features are used, and general performance metrics.

Analytics data does NOT include:

  • Names, email addresses, photos, or face data
  • Advertising identifiers
  • Precise location data
  • Any information that can directly identify a user

Analytics data is used only to improve application performance and user experience. It is not used for advertising, tracking users across apps or websites, or linking data to a user's identity.

5. Third-Party Data Sharing

  • We do not share face data with any third parties.
  • No third-party SDKs, analytics services, or cloud services have access to face data.
  • Analytics providers receive only anonymized, aggregated usage statistics.
  • Third parties do not store face data on our behalf.

6. Offline Processing

All photo processing, including face detection and compliance checks, is performed fully offline on the user's device. No internet connection is required, and no photos or biometric data leave the device.

7. Children's Privacy

The Application does not knowingly collect personal data from children under the age of 13. Since the Application does not collect or store personal or face data, there is no intentional data collection from minors.

8. Data Security

We take reasonable measures to protect user data. Because sensitive processing is performed locally on-device and not transmitted, the risk of data exposure is minimized.

9. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page, and the "Last updated" date will be revised accordingly. We encourage users to review this Privacy Policy periodically.
